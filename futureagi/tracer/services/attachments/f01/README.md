### Application recording preview

The signed-in Trace drawer lazily reads `GET /tracer/v1/projects/{project_id}/attachments/occurrences/{occurrence_id}/recording-preview?trace_id=…&span_id=…`. The occurrence must be bound conversation audio visible on this exact parent. The response is the Voice recording projection (`occurrence_id`, `parent`, `state`, plus `manifest` only when ready); a segmented recording names its first timeline occurrence. This endpoint neither mints a grant nor changes the F01 manifest API.

A successful authorized peaks byte GET may include `X-Attachment-Peaks`: bounded JSON `{v:1,sample_rate,channels,frame_count,levels:[{frames_per_bucket,buckets},…]}` for the selected immutable derivative. Bytes are level-major then channel-major little-endian signed int16 min/max pairs. The header is absent on ordinary media and errors. Missing peaks never block playback.
