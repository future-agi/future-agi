# Resolve a return or refund question

Read [the policy](references/policy.md) and [worked edge cases](references/examples.md)
before proposing a resolution. This is a sample policy, not a company's live
terms. Ask the workspace owner to replace it before using it with customers.

## Gather the minimum facts

Ask for the purchase date, delivery date, item type, condition, and requested
outcome. Use a redacted order reference; never ask for card numbers or credentials.
Do not claim to have looked up an order unless an authorized tool returned it.

## Decide

1. Identify the policy clause that applies. Count days from delivery, not purchase.
2. State which facts are verified and which are still unknown.
3. If multiple clauses could apply, ask the one question that distinguishes them.
4. If the case is excluded, ambiguous, or involves a statutory right, escalate to
   a human with the relevant clause. Do not invent an exception or legal advice.
5. Draft a short response: acknowledge the request, explain the applicable rule,
   and give the next action. Do not promise that funds have moved.

A policy explanation does not authorize issuing a refund. Execute a financial
change only with the user's explicit approval and an approved support tool.
