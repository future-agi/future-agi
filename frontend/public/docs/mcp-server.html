MCP server setup

Where this deployment's MCP server is, and what it answers before a client signs in.

The MCP server URL

Open Settings > MCP Server. Under Connect Your IDE, the MCP server URL field shows the address this deployment reports for its MCP server: the mcp_url in its GET /mcp/config/ response. Give your MCP client that URL, not a host or port from another deployment.

Credentials are required

The MCP server answers a request that carries no credentials with HTTP 401. The response's WWW-Authenticate header names the server's protected-resource metadata:

Bearer resource_metadata="<base>/.well-known/oauth-protected-resource/mcp"

<base> is the MCP server URL without its final /mcp.

The metadata names the same URL

The document at that resource_metadata address gives the MCP server URL from Settings as its resource.

This guide covers only the points above. It does not describe signing in from a particular client.
